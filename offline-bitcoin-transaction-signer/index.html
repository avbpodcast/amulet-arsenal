Amulet Transaction Creator

Sign Bitcoin transactions offline.

Amulet Transaction Creator builds a Bitcoin transaction as a PSBT and signs it on a computer that never goes online. It is one HTML file, so the signing machine can be any old laptop with the network switched off. No hardware wallet and no installed software.

Beta · under test · free and open-source · single HTML file

For real funds: download, check the SHA-256, then run it from disk on an offline machine.

What it does

  • Build tab: makes an unsigned PSBT from your watch-only key, the coins you choose to spend, the recipient and the fee.
  • Sign tab: takes a PSBT and your seed and returns a signed one. This tab makes no network calls at all.
  • Uses the standard PSBT format (BIP-174), the same one Sparrow, Electrum and hardware wallets use.
  • Signs for Native SegWit (BIP-84, bc1q) accounts, with optional BIP-39 passphrase.
  • The seed stays in the tab and is wiped when you press Forget seed or close it.

How to use it

  1. 1Build the transaction onlineOn your everyday computer, load your watch-only key, pick the coins to spend, and enter the address, amount and fee. Looking up your coins is the only online part.
  2. 2Carry it to the offline machineMove the unsigned PSBT across by USB stick or QR code.
  3. 3Check and signOn the offline machine, open the Sign tab, read the address and amount again, then enter your seed and sign.
  4. 4Carry it back and broadcast onlineMove the signed PSBT back and send it with the Broadcaster, or with any wallet that accepts PSBTs.

Steps marked "online" need the internet. Everything else runs offline.

Good to know

  • This tool is in beta and still under test. Try it with a small amount first.
  • Signing currently covers Native SegWit (BIP-84) accounts.
  • Always compare the recipient address on the offline machine with a second source. Malware on the online computer can swap an address before it reaches the PSBT.

Questions

What is a PSBT?

A Partially Signed Bitcoin Transaction (BIP-174) is a standard file for a transaction that is put together in steps: one tool builds it, an offline tool signs it, and another broadcasts it.

Do I need a hardware wallet to sign offline?

No. Any computer that stays offline can do the signing. A hardware wallet is one way to keep keys off the internet; a permanently offline laptop running a verified file is another.

Does my seed ever leave the page?

No. The Sign tab contains no network code, and the seed is held in memory only until you close the tab or press Forget seed.
