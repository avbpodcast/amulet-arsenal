Local configuration · stored only on this device
One mempool.space-compatible REST endpoint per line. The Scryer rotates between them in round-robin order, so each explorer sees only its share of your addresses — lower rate-limit pressure, better privacy, and resilience if one is degraded. Replace with your own node URL for full privacy.
The only stopping condition: scan continues per chain until this many consecutive empty addresses are seen. Standard is 20. A wallet with continuous activity tolerates a small gap (e.g. 3); a sparsely used one needs the full 20.
After a complete refresh succeeds, the Scryer schedules the next one this many minutes later (5–120). A countdown chip at the top of the page shows time remaining. Set to 0 to disable auto-refresh and only update on demand.
Milliseconds between calls. mempool.space's public API limits to ~60/minute, so anything below 1000 ms risks an HTTP 429 blackout for several minutes. Set to 0 only if you are pointing at your own node.
⚠ Below the public rate limit. mempool.space will refuse further calls for several minutes if it sees more than ~60 per minute. Use this setting only with your own node.

Import from vault file

Watch-only extraction · seeds and private keys never enter Scryer state
What we control: the seed lives only in a narrow function scope, the 64-byte seed buffer and the Argon2id-derived AES key are explicitly zeroed in try/finally blocks, password input fields are wiped immediately after each decrypt, nothing seed-related is written to localStorage or the DOM, and no network call is made during decryption or derivation — all crypto is inlined in this single HTML file (audit the SHA-256 in the bundle header). Watch-only output (xpub/zpub/addresses) cannot spend coins — that's mathematics, not a promise.

What we can't fully control: JavaScript strings are immutable, so individual seed-word strings live in the V8 heap until the next garbage collection. A malicious browser extension or anyone with debugger access to your browser process can in principle observe that brief window. The maximum-paranoia path is now built in: open Amulet Vault, click 👁 Watch-only export, and import the resulting .json here instead of the encrypted backup. The Scryer never decrypts anything, and no seed ever exists in this tab.

About to contact third-party servers

Watch-only balance lookup · no private keys are ever transmitted
The Scryer is offline by default. To read balances it has to query public block-explorers with each of your watch-only addresses. The Scryer rotates between the listed endpoints to spread the load and avoid rate limits. Each operator sees only the share of addresses that lands on their server, plus your IP address. None of them can see, derive, or spend anything.
