🛡️ How to use this page offline

Going offline removes the main attack surface: no extension, tracker, or webpage can exfiltrate your seed if the network is physically disconnected. Follow these 4 steps.

  1. Save this page to disk. Press Ctrl+S (Windows / Linux) or ⌘+S (Mac). In the save dialog choose “Webpage, Complete” or “Webpage, HTML Only”. A .html file lands in your Downloads folder.
  2. Disconnect from the internet. Turn off Wi‑Fi, unplug the Ethernet cable, or enable Airplane Mode. Do not skip this — simply closing tabs is not enough.
    WindowsClick the Wi‑Fi / network icon in the taskbar → turn Wi‑Fi off, or press Fn+F2/airplane key.
    macOSMenu bar → Wi‑Fi icon → turn Wi‑Fi Off. For Ethernet, unplug the cable.
    LinuxTop bar network applet → Disconnect / Turn Off. Or nmcli networking off.
    MobileSwipe down the Control Centre / Quick Settings → tap Airplane Mode ON.
  3. Open the saved file. Go to your Downloads folder and double‑click the .html file you just saved. It will open in your browser from disk — no server, no network.
  4. Verify the green pill. In the top‑right of this page the status should flip to OFFLINE · SAFE (green). Only then generate your wallet.
Pro tip: for life‑changing amounts, use a clean machine that has never been online, a live OS from USB (e.g. Tails), or a dedicated hardware wallet. This page is a big step up from online generators, but an air‑gapped device is better still.
