This tool boots offline. Loading and verifying your transaction below happens entirely on this machine. The only network call this tool ever makes is the one broadcast you confirm at the bottom.

Tor mode is on. Broadcast and reachability checks will use the .onion endpoints listed below.

For .onion addresses to actually resolve, this page must be loaded in Tor Browser (or a regular browser configured to route requests through a Tor proxy). A normal Chrome or Firefox cannot reach .onion addresses and the requests will fail at the network layer.

Load signed transaction

Paste a signed PSBT (base64) coming out of the Amulet Signer, or a raw transaction hex if you already extracted one. The format is detected automatically.

Two valid inputs

Signed PSBT looks like a long base64 string starting with cHNidP8. The Amulet Signer produces this. The Broadcaster will finalize it locally and extract the raw transaction before broadcasting.

Raw transaction hex looks like a long string of hex characters (often starting with 0200000000 for segwit transactions). Other wallets like Sparrow and Electrum can export this.

Either way, this tool only reads the transaction. It does not need your seed and will refuse to accept one if you paste it by mistake.

Verification

Read this carefully before broadcasting. Once a transaction goes out, it cannot be recalled.

Broadcast

Four steps. Each one waits for your explicit go-ahead. Nothing reaches the network until the very last confirmation.

1 Acknowledge the transaction

Read the verification panel above. Look at every recipient address and every amount. If anything looks wrong, do not continue.

2 Go online to find broadcast nodes

Next, the tool will reach out to the chosen broadcast node and check that it is alive and ready. Nothing will be broadcast at this stage. A separate, final confirmation is needed before any transaction leaves this machine.

3 Pick a node and start the broadcast

The nodes below have been contacted. The first one that came back ready is selected by default. Click any other ready (green) node to switch the selection. Failed nodes can not be picked.
