The Arsenal

// 01 · Launcher Amulet Main

The single-file launcher for the entire Arsenal. A local HTML page that lists every tool by trust zone and opens the right one with a click. Bookmark it once and you have your toolbox; the rest of the Arsenal sits one tap away.

  • One file, no installs, opens offline
  • Lists all tools split by air-gapped vs online companion
  • Live online / offline indicator at the top
  • Audit-friendly: under 500 lines of plain HTML + CSS
Available Open →

// 02 · Generator Amulet Generator

An offline wallet generator built around excellent entropy and full transparency. It runs on your machine, never touches the network, and hands you back every bit of randomness it used, so you can verify exactly what shaped your keys.

  • Excellent entropy, with every source bit delivered for verification
  • Offline and local-only, air-gap friendly by design
  • "Nothing up our sleeve" numbers: all constants public and auditable
  • Plain-text or encrypted output, your choice
  • Silent Payments, Taproot, Bech32, plus full legacy address support
Available Open →

// 03 · Vault Arsenal Vault

A local encrypted vault for seed phrases, time-locked redeem scripts, and watch-only public keys. Everything stays on your disk, sealed by a passphrase only you hold. A watch-only export feeds the online side without ever exposing a seed.

  • Authenticated encryption (AES-GCM-256)
  • Argon2id key stretching
  • Watch-only export for the online tools
  • Zero telemetry, zero cloud, zero accounts
Available Open →

// 04 · Scryer Amulet Scryer

A watch-only balance viewer. Reads watch-only exports from the Vault, queries multiple block explorers in rotation, and never sees a seed or a private key. The online half of the cold-wallet workflow.

  • Reads BIP-44, BIP-49, BIP-84 extended public keys
  • Multi-explorer rotation with rate-limit safety
  • Gap-limit-aware address discovery
  • Auto-refresh every ten minutes
Available Open →

// 05 · Transaction Creator Amulet Transaction Creator

Build and sign Bitcoin transactions locally. Loads a wallet from the Vault, the Scryer, or any wallet .txt. Signs PSBTs entirely offline, with the option to look up balances online behind an explicit consent prompt.

  • BIP-174 PSBTs end-to-end (build + sign in one file)
  • Air-gap-friendly: same file on the build and signing machines
  • Optional online lookup via your choice of explorer (clearnet or Tor)
  • Address explorer with one-click UTXO import
Beta · under test Open →

// 06 · Broadcaster Amulet Broadcaster

Push a signed PSBT or raw transaction hex to the Bitcoin network. Eleven clearnet endpoints + two Tor onions, all editable. Four-step gated confirmation flow before anything goes online. Per-row first-confirmation polling so you can leave the tab open and watch the badge flip.

  • Esplora, JSON, form, and manual broadcast adapters
  • Strict Tor / clearnet network isolation
  • Already-broadcast recovery with confirmation tracking
  • Editable endpoint list with API-key support
Available Open →

// 07 · Timelock Amulet Timelock

Generate Bitcoin time-locked redeem scripts (P2SH and P2WSH) with verifiable SHA-256 checksums. Plaintext .txt backup format that the Vault can encrypt and store alongside seed wallets.

  • OP_CHECKLOCKTIMEVERIFY redeem scripts
  • P2SH and P2WSH wrapping
  • SHA-256 checksum on every backup
  • Imports into the Vault as a first-class wallet type
Release candidate Open →

// 08 · Silent Silent Amulet

A silent-payment wallet (BIP-352). Share one static address, receive to a fresh output every time. No address reuse, no on-chain link to your identity.

  • Native BIP-352 silent payments
  • Stealth receive, standard send
  • Watch-only mode for cold setups
Beta · under test

// 09 · Relic Amulet Relic

A pure-Python recovery script for vault-native and AMLT-encrypted .enc files. Last resort if the HTML tools won't open. Audit-friendly: stdlib plus cryptography and argon2-cffi, nothing else.

  • Decrypts AMULET_WALLET_V1 and AMLT-format payloads
  • Argon2id key derivation, AES-GCM authentication
  • Pure Python, no browser, no installer
Available · ships in repo

We test before we release.

A bug in a wallet isn't an inconvenience. It's someone's sats, gone for good. That's why every tool we ship runs offline by default and stays on the bench until it survives everything we can throw at it: line-by-line review, broken inputs on purpose, edge cases, the lot.

Other shops race to be online first. They burn your hard-earned money and your harder-earned time on broken flows and half-finished promises. That isn't shipping. That's beta in production.

You are not our test bench.
The sovereign do not pay to be alpha-testers. The forge eats failures; you should never see them.

This is what bitcoin software should have done from the start: deliver quality. Don't over-promise. Don't under-deliver. If it isn't battle-tested, it doesn't leave the forge. Every future release follows the same rule.

No forge produces a flawless blade every time. A rare edge case can hide in the corners. But the basics are tested, the normal use cases are covered, and nothing leaves this bench until we'd trust it with our own keys.
