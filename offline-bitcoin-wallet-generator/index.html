Amulet Generator

Offline Bitcoin wallet generator.

Amulet Generator creates a 12 or 24 word BIP-39 seed phrase and the Bitcoin wallets that come from it, inside one HTML file, on a computer that is not connected to anything. You can add your own randomness from dice or playing cards, and the tool shows you every bit it used.

What it does

  • Creates a 12 word (128 bit) or 24 word (256 bit) BIP-39 seed phrase.
  • Lets you mix in your own randomness from dice, playing cards or keystrokes, on top of the browser's secure random generator.
  • Derives Legacy, Native SegWit (Bech32) and Taproot addresses, plus Silent Payments.
  • Has an optional reproducible mode: your written-down dice or card draws alone can rebuild the same wallet later.
  • Makes no network requests. One self-contained file, no fonts, scripts or images loaded from anywhere.

How to use it

  1. 1Download and verify the fileSave the tool to disk and compare its SHA-256 with the published hash before you trust it.
  2. 2Go offlineTurn off Wi-Fi and unplug the network cable. Open the saved file from disk and check that the tool reports no network.
  3. 3Generate the walletChoose 12 or 24 words. Add dice or card entropy if you want randomness you can see for yourself.
  4. 4Write the seed downPut the words on paper or steel. Never photograph them and never type them into a connected device. Use the wipe button before closing the tab.

No step needs the internet. The whole tool runs offline.

Good to know

  • By default the tool uses your browser's built-in secure random generator, and that is enough. Dice and cards are an option if you would rather not rely on the browser alone.
  • Running the tool from this website is fine for trying it out. For real funds, save a copy, verify it, and run it on an offline computer.
  • A checksum only protects you if it comes from a different place than the file itself. So also compare the hash with the one in the source repository.

Questions

Is it safe to generate a Bitcoin seed in a browser?

It depends on how you run it. Amulet Generator is a single file with no network code, meant to be saved, verified against its SHA-256 hash, and opened on an offline computer. Used that way, the seed never touches the internet.

Can I make a seed with dice or playing cards?

Yes. You can enter dice rolls or card draws as extra entropy. The tool mixes them with the browser's secure random generator using SHA-256 and records what it used, so you can reproduce the result.

Does it cost anything or need an account?

No. It is free and open-source under the MIT licence, with no account, no install and no telemetry.
