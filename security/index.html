Security model

How the tools handle your keys.

Every Amulet tool is one HTML file that you can save, check and run on a computer that is connected to nothing. This page states plainly how the tools are built, which ones go online, what they keep in your browser, and what they cannot protect you from.

For real funds: download, check the SHA-256, then run the file from disk on an offline machine.

How they are built

  • Each tool is one self-contained HTML file. There is no installer, no account and no server-side part.
  • No scripts, stylesheets or fonts are loaded from other servers. The open-source libraries the tools rely on (noble, scure, argon2-browser, slip39-js) are bundled inside the file, so the file you verify is the code that runs.
  • Random numbers come from the browser's secure generator (crypto.getRandomValues). The wallet generator and Beyond: the Hand also let you use your own dice or cards.
  • The Vault encrypts with Argon2id and AES-256-GCM. The Shamir tool splits and rejoins shares following SLIP-0039.
  • The code is public under the MIT licence on Codeberg.

Which tools go online

Creating and storing keys needs no connection. Some tools exist to talk to the Bitcoin network, and they say so.

  • Amulet Generator, Vault, Shamir Shared Split and Picker have no online features. They contain no addresses of block explorers or other services.
  • Amulet Scryer contacts block explorers to read balances. It asks first and shows which servers it will contact. Those servers see the addresses it looks up and your IP address.
  • Amulet Broadcaster sends a finished, signed transaction to block explorers, over the normal internet or over Tor.
  • Amulet Transaction Creator can contact block explorers. Signing itself needs no connection.
  • Silent Amulet can scan for payments through an indexer you choose, and Timelock can contact block explorers and the drand time beacon.

What stays in your browser

  • Every tool remembers your light or dark theme in the browser's local storage.
  • Scryer saves your watch list (public keys only) and its settings in local storage, so they are there on your next visit. “Reset local data” in the tool removes them.
  • Silent Amulet can save a wallet in local storage. It is encrypted with your password (PBKDF2-SHA256 with 250,000 rounds, then AES-GCM).
  • The Broadcaster and Transaction Creator remember the network and the servers you selected.
  • Nothing is sent to AVBforge. Opening a tool from this website is an ordinary page request, so the web host sees your IP address as with any site. A saved copy run from disk avoids even that.

What they cannot protect you from

  • A computer, browser or browser extension that is already compromised can read what you type. Use a clean, offline machine for real funds.
  • Only the Vault sets a browser-level network lock (a Content Security Policy). For the other tools, the protection against leaks is running them with the network off.
  • A tool opened from the website is the copy served at that moment. A saved, verified copy cannot change behind your back.
  • A checksum only protects you if it comes from a different place than the file. Compare with the source repository as well.
  • The tools cannot protect what leaves the screen: photos, screenshots, clipboard managers, printers and shoulder surfers.

Questions

Can a tool send my seed somewhere?

The Generator, Vault, Shamir tool and Picker have no online features. The surest protection is to run any tool on a computer with the network off: a file that cannot reach a network cannot send anything.

Have the tools had a formal third-party audit?

No formal third-party audit has been published. The tools are checked against the official Bitcoin test vectors, the source is public, and every release has signed checksums so anyone can review exactly what is shipped.

Why a single HTML file instead of an app?

A single file can be read in any text editor, needs nothing installed, and has one SHA-256 hash you can compare. It runs inside the browser's sandbox instead of with full access to your computer.
