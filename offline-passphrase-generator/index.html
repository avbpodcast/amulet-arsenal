Amulet Picker

Offline passphrase generator.

Amulet Picker builds a strong passphrase from random words, in one HTML file that makes no network requests. It draws from a pool of 10,000 words, shows the strength as you go, and gives you a fingerprint so you can check later that you wrote it down correctly.

Available · free and open-source · single HTML file

For real funds: download, check the SHA-256, then run it from disk on an offline machine.

What it does

  • Draws each word uniformly from 10,000 unique words (BIP-39, EFF Diceware, a custom list and 100 extras).
  • Each word adds 13.29 bits of entropy: six words give about 80 bits, eight words about 106.
  • Uses the browser's cryptographically secure random generator with rejection sampling, so there is no bias.
  • Shows a fingerprint (a short code and a small glyph) to catch transcription errors when you re-enter the passphrase.
  • Can add a few random digits and symbols for sites that insist on them.

How to use it

  1. 1Open the file offlineSave it, verify its SHA-256, and open it with the network off.
  2. 2Pick wordsPress Auto-pick for an eight-word passphrase, or pick one word at a time until the meter is where you want it.
  3. 3Record it with its fingerprintWrite down the passphrase and the fingerprint. Later, re-type it to confirm both match.

No step needs the internet. The whole tool runs offline.

Good to know

  • The strength comes from random draws. Do not swap words for ones you like better.
  • The optional pepper adds robustness if the device's random generator is ever weak. It does not add entropy.
  • Words work as-is as an Amulet Vault master password. Extra digits and symbols are only for third-party sites with rigid rules.

Questions

How many words do I need?

Eight words from this pool give about 106 bits of entropy, which the tool rates as very strong. Six words give about 80 bits.

Why words and not random characters?

Words are far easier to write down, read back and type without mistakes, and with a 10,000 word pool they reach the same strength with a manageable length.

Is anything sent over the internet?

No. The tool is one self-contained file that makes no network requests and works fully offline.
